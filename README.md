# Aptura-Tech-Solutions-Internship-Week-3

## 📦Task 1-Object-Oriented Inventory System

A Python-based Inventory Management System developed using **OOP, Streamlit, and JSON**. The application provides an interactive interface to manage products and inventory records.

## ✨ Features

- 📊 Inventory Dashboard
- ➕ Add Products
- ✎ Update Products
- 🗑️ Remove Products
- 🔍 Search Products
- 📋 View Inventory Records
- 💰 Calculate Product Total Value
- 💾 JSON Data Persistence
- ✅ Input Validation

## 🛠️ Technologies

- Python
- Streamlit
- JSON
- Object-Oriented Programming (OOP)

## ▶️ Run the Project

Install Streamlit:

```bash
pip install streamlit

Run the application:

streamlit run app.py
```


## Task 2-🔄 Automated Data Pipeline

A Python-based **Automated Data Pipeline** developed as part of the **Aptura Tech Solutions Python Internship – Week 3**.

The project processes raw CSV data through validation, cleaning, transformation, analytics, and export stages using a professional Streamlit interface.

## ✨ Features

- 📂 CSV Data Upload
- 🔍 Data Validation
- 🧹 Data Cleaning
- 🔄 Data Transformation
- 📊 Data Analytics
- 💾 Clean Data Export
- 📝 Error Log Generation

## 🛠️ Technologies

- Python
- Pandas
- Streamlit

## 🔄 Workflow

```text
Upload → Validate → Clean → Transform → Analyze → Export
````

## ▶️ Run the Project

```bash
pip install streamlit pandas
streamlit run app.py
```
